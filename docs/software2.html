Complete Installation Instructions

The library is written in Python. We recommend installing MEYELens in a dedicated Python environment.

Recommended install

Create and activate a dedicated Conda environment, then install MEYELens with the standard PyTorch dependency set.

Command 
conda create -n meyelens python=3.10 -y
conda activate meyelens
pip install meyelens[pt]
Tip: This installs MEYELens together with a standard PyTorch dependency set. Depending on your system, PyTorch may run on CPU unless GPU support is configured separately. GPU setup results in much higher performances due to parallel computation.

PyTorch GPU support (optional)

If you want GPU acceleration, configure PyTorch first by following the official installation guide for your platform. After verifying that PyTorch can access the GPU, install MEYELens:

Warning: GPU acceleration depends on your operating system, CUDA/cuDNN compatibility, and PyTorch version. Follow the official Pytorch installation guide for your platform before installing MEYELens.
Command 
pip install meyelens
Tip: This install MEYELens alongside your manually configured PyTorch library.

Headless package

If you want only the core Python package without the PyQt GUI, install the separate headless distribution.

Command 
pip install "meyelens[headless]"

To install the headless package with PyTorch dependencies:

Command 
pip install "meyelens[headless,tf]"
Warning: Do not install meyelens and "meyelens[headless]" into the same environment. Use separate environments if you need to test both distributions.
